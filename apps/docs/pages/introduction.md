# 介绍

Daisu UI · 袋鼠 UI 是面向 ReactLynx 的组件库，提供基础、导航、录入、反馈和数据展示组件，以及独立的浏览器 Demo。

## 组件与交互

每个组件都有独立文档和示例，说明属性、事件、自定义内容与主题。组件通过公开入口导入，样式随入口自动加载。

## 目标平台

组件主要使用 Lynx 原生元素。浏览器预览运行于 Lynx Web，媒体播放、图片裁剪等能力通过显式浏览器后端启用；原生宿主能力由消费项目提供。
