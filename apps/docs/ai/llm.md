# LLM 文档

向 AI 提供与当前组件版本一致的文档，可以帮助它准确使用属性、事件和平台能力。

## 文档入口

| 文档 | 用途 |
| --- | --- |
| [llms.txt](./llms.txt) | 组件目录、公开入口与核心限制，适合作为首次检索入口 |
| [llms-full.txt](./llms-full.txt) | 完整组件约束、组合方式及宿主能力边界 |
| [组件生成约束](./component-ai-notes.txt) | 逐组件的状态、事件和平台规则 |

两个文件随本次文档构建生成可访问的副本，内容来自仓库的 docs/ui 目录。可直接打开链接，将地址交给支持网页读取的 AI 客户端。

## 提问示例

```text
请先阅读 Daisu UI 的 llms.txt，再按需查阅 llms-full.txt。
使用 Form、FormItem、Input 和 Button 实现用户资料表单。
请核对 value/onChange 的类型，采用受控状态，并支持深色模式。
目标为 ReactLynx，页面文字使用 text 元素。
```

## 检索顺序

先确认组件的公开属性与事件，再查找相应独立示例。涉及浏览器媒体、上传、键盘或原生手势时，结合平台说明核对实际支持范围。

## 版本与验证

文档站页头显示当前组件版本。版本菜单提供已有版本的更新记录；生成代码应使用当前版本的 API，并运行类型检查、测试和构建。
