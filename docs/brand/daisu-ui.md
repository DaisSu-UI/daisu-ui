# Daisu UI · 袋鼠 UI 品牌图标

图标将字母 D 与袋鼠侧面轮廓结合：长耳与口鼻构成上部识别特征，D 的弧形外轮廓和内部留白形成主体。使用单色几何形状，便于缩放和反白展示。

本稿为直接绘制的 SVG 矢量设计，PNG 从 SVG 渲染导出。

## 资源

| 文件 | 用途 |
| --- | --- |
| [daisu-ui-icon.svg](../../src/assets/brand/daisu-ui-icon.svg) | 橙底白标的圆角图标，适合组件库入口和头像 |
| [daisu-ui-icon.png](../../src/assets/brand/daisu-ui-icon.png) | 图标的 1024 × 1024 PNG，圆角外部透明 |
| [daisu-ui-mark.svg](../../src/assets/brand/daisu-ui-mark.svg) | 透明背景的橙色标志，适合白底文档和品牌组合 |
| [daisu-ui-mark.png](../../src/assets/brand/daisu-ui-mark.png) | 标志的 1024 × 1024 透明 PNG |

品牌橙：`#FF6A00`。反白色：`#FFFFFF`。SVG 画布统一为 `1024 × 1024`，主标志保持相同的位置、比例和留白。

## 使用

优先使用 SVG，保持原始宽高比；不要单独拉伸耳朵、字母或改变内部留白。文档名称使用 **Daisu UI · 袋鼠 UI**，图标本身不包含文字。

文档站页头和 favicon 已使用 `daisu-ui-icon.svg`，发布副本位于 `apps/docs/public/brand/`，保留原始宽高比并完整展示图案。
