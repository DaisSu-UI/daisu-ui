# Daisu UI 组件实现状态

组件按基础、导航、录入、反馈和数据展示分类，每个组件提供独立详情。
参数以本库实际公开类型与组件文档为准，Lynx 能力通过本地技能核对。

## 每个组件的完成条件

1. 从 `packages/daisu-ui/src/index.ts` 导出可复用的组件与 TypeScript 参数。
2. 独立详情页按在线 Demo 的分组、文案、尺寸、间距和交互复刻，支持深色模式。
3. 更新 `docs/ui/components/<组件>.md`、`llms-full.txt` 与本清单；明确参数映射及平台限制。
4. 运行 `npm test`、`npm run build`，在 H5 实际交互并截图核对。
5. 一个组件一个提交，验证后推送 `origin/developer`；不将待实现条目伪装成可用组件。

原有 UI 库、路由和示例此前尚未提交，首次提交一并建立可构建的基线。
只有完成 API、交互与示例核对的组件才标记完成。
H5 验证不能替代 Flutter 内 iOS / Android 真机验证。

## 参数映射原则

- Vue `v-model` 映射为 React `value` / `onChange`；无需强行模拟 Vue slots 或 uni-app 专有事件。
- `custom-class` 映射为 `className`；slot 内容映射为 ReactNode。
- 不引入 uni-app 运行时，不依赖浏览器 DOM；宿主能力走 `src/lib` 协议。
- 不支持的参数在组件文档逐项注明原因，不提供无效果的占位参数。
- 组件详情只展示已经可用的能力；原业务页面的组件不随 Demo 改版擅自替换。
