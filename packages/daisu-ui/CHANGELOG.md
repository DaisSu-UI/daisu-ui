# 更新日志

记录 Daisu UI 的版本变化。npm 组件包名为 `@daisu-ui/ui`，源码与自动发布入口为 GitHub。

## 0.1.0-beta.7

2026-11-26 · 修复原生图标渲染

- 图标 SVG 颜色替换使用兼容的 split/join，移除对 String.replaceAll 的依赖，修复原生主线程 1101 与后台线程 201 的图标渲染异常。
- 增加缺少 String.replaceAll 时的回归检查，覆盖重复颜色替换和 XML 转义。

## 0.1.0-beta.6

2026-11-26 · Lynx 4.0 基线与统一弹层

- Bundle 编译目标调整为 Lynx 4.0，开发类型固定为 `@lynx-js/types@4.0.0`，公开类型范围为 `^4.0.0`；更新宿主模板、接入示例及平台说明。
- Popup 新增可选 `title`，统一左对齐标题、40px 圆形关闭按钮、24px 图标和 16px 顶部/侧边距；底部圆角弹层采用 32px 顶部圆角。
- 同步 Dialog、ActionSheet、日历、级联选择、多选面板、图片/视频预览和 Curtain 的关闭样式；视频预览默认关闭位置调整为右上角，显式左上角配置仍可用。
- Demo 的主题切换、分段器、签名、RootPortal 与 Tabbar 弹窗复用公共弹层，修复本地开发模式 Demo 入口识别。
- 根目录 README 与许可证成为包内副本的唯一来源，清理外部技能副本、迁移记录和重复文档。
- 文档首页支持组织根地址自动发布，组件资料与 CLI 离线快照按版本同步。

## 0.1.0-beta.5

2026-11-26 · 导航栏修复与 GitHub 自动发布

- 修复业务导航栏返回箭头缺失，统一使用内置 SVG 图标。
- 新增业务导航栏 `backButtonEffect="glass"`：支持宿主提供的 iOS Liquid Glass 材质，并补充平台差异说明及示例。
- 统一仓库和 npm README 展示，源码链接更新为 GitHub。
- npm 发布迁移到 GitHub Actions，加入 Token 身份与目标包权限检查、main 发布预演及版本标签发布流程。

## 0.1.0-beta.0

2026-11-25 · 开发中

- 将应用内通用 UI 提取为独立 ReactLynx npm 包。
