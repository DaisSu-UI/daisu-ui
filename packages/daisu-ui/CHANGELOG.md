# 更新日志

记录 Daisu UI 的版本变化。组件包通过 GitLab 分发并由 npm 安装，尚未发布到 npmjs。

## 0.1.0-beta.2

2026-11-25 · Git 发布

- 通过受保护的源码版本 Tag 自动执行测试、类型检查、Demo/文档构建和独立组件包校验。
- 自动生成 `npm-dist` 发布分支及 `npm-v*` 安装标签，产物保留 JSX、类型声明和自动样式加载。
- 提供本地 Docker Runner 配置和一键 Git 发布命令，无需发布到 npmjs。

## 0.1.0-beta.1

2026-11-25 · 开发中

- 增加随仓库使用的本地 stdio MCP 文档服务，提供组件、API、Demo、主题变量、全文搜索与更新记录查询；补充通用 JSON、Cursor、VS Code 和 Codex 配置及真实客户端集成测试。
- 文档站增加分组指南、设计系统与 AI 导航，统一左侧目录和顶部菜单，提供 AI 总览、文档搜索及版本更新定位，支持键盘、触屏与明暗主题。
- 清理组件注释、使用指南、示例内容及远程资源引用。
- 内置图标切换至 Tabler Icons 3.53.0，保留现有 305 个图标名称。
- 演示插画、视频与旋律使用本仓库生成的本地资源，水印使用 Daisu UI 标志。

## 0.1.0-beta.0

2026-11-25 · 开发中

### 新增

- 将应用内通用 UI 提取为独立 ReactLynx npm 包。
- 提供保留 JSX 的 ESM、TypeScript 声明和完整组件样式。
- 从组件入口自动加载样式，支持生产构建 tree shaking，无需单独导入 CSS。
- 提供独立 router、router/runtime 与 utils 入口。
- 提供独立交互 Demo 与 Web 组件文档站，包含使用示例、API 表格和本页目录。
- 提供站内源码查看器，支持高亮、复制与源码链接直接访问。
- 增加更新日志页面及组件分类导航。

### 优化

- 统一组件文档的说明、代码和交互预览布局。
- 文档构建同步生成最新组件库与 Demo，避免预览使用旧产物。

### 修复

- 修复文档底部源码链接触发下载的问题，改为站内查看。

### 版本说明

- 业务组件及 Flutter 宿主适配由应用维护。
- 首个 beta，原生平台完整回归待完成。
